# READ ME

Repository containing code for the exploratory analysis of synthetic claims data "[Synthetic Patient Data in OMOP](https://console.cloud.google.com/marketplace/product/hhs/synpuf?project=project-d60bc1f8-9487-4a43-958)" available on Google Cloud. The analysis is focused on exploring the relationship between influenza, cardiac episodes, and the potential impact of flu vaccination.

Poetry is used as the package manager.
